🎙️ Talk to your Mac

Free voice control is installed. The entire manual is below — 60 seconds, three steps.

Step 1 — Permissions (one time)

macOS blocks every app until you say OK — no installer can skip this, it's the OS itself. The installer already popped the Allow dialogs for you; if you missed one, run bash prime_permissions.sh from the terminal app you'll use.

  1. Microphone — click Allow in the popup
  2. Accessibility — click Allow in the popup
  3. Input Monitoring — the one manual toggle: System Settings → Privacy & Security → flip it on for your terminal app (Apple offers no popup for this one)
  4. Screen Recording — macOS 26+, click Allow in the popup; only needed for “click the … button”

If you previously denied one, no popup re-appears — flip it by hand in Settings. Restart your terminal after.

Step 2 — Talk

Hold Right Option ⌥, speak, release.

That's the whole thing. Release the key and your Mac does it. Press Esc to quit.

Tip: double-click Voice Control.command anytime to start — no terminal typing needed.

Step 3 — Try saying…

“open notes” “set volume to 30” “play” “set a timer for 5 minutes” “search best pizza near me” “click the Reply button” “what time is it” “lock”

Say “help” anytime to hear everything it understands. It costs $0 per command — everything runs on your Mac.

Want it always listening?

Double-click Voice Control (Always On).command — then just talk. No key to hold.

It hears speech, does the command, and goes back to listening. Things that aren't commands are ignored silently. Ctrl-C or close the window to stop.

There's no wake word — any speech wakes it. In a noisy room (TV on, people talking), the push-to-talk key is calmer. During install you can also choose start at login so it's always ready, even after a reboot.

Use your iPhone as the mic (Mac mini has none built in)

The installer already tried to set this up for you: if your iPhone was nearby with the same Apple ID, Wi-Fi and Bluetooth on, it set your iPhone as the Mac's input and saved VOICE_MIC=iPhone — the app then prefers your iPhone whenever it's in range and falls back to the Mac default otherwise. To re-run it any time: bash prime_permissions.sh. You can also force a mic per run with --mic NAME (e.g. --mic iPhone).

Option A — built-in, free, no app: on your iPhone and Mac, sign into the same Apple ID with Wi-Fi and Bluetooth on, keep the iPhone nearby and unlocked. Then on the Mac: System Settings → Sound → Input → choose your iPhone. Done.

Option B — WO Mic (free app): install WO Mic from the iOS App Store plus the free Mac client from wolicheng.com, connect over Wi-Fi, then pick “WO Mic” as the input. Works fine; the app is ad-supported and reviews are mixed, so try Option A first.

If something doesn't work

  • Nothing happens at all → a permission in Step 1 is off. This fixes it 9 times out of 10.
  • “I didn't understand” a lot → make sure Ollama is running: open Terminal and run ollama serve. It handles unusual phrasing.
  • “Click the … button” can't see anything → grant Screen Recording (macOS 26+) in Step 1.
  • Weird phrasing works but slowly → normal. The instant path handles exact commands; the ~1-second local AI handles the rest.
  • Always-listening triggers on the TV → expected — there's no wake word. Use push-to-talk in noisy rooms, or raise the bar with --sensitivity 4.5.
  • Start-at-login asks for Microphone permission again → normal. macOS grants mic access per app; allow it once for Python and it sticks.
